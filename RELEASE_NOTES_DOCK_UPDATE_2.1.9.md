# DockUpdate 2.1.9

DockUpdate now accepts the complete AppDock 9.6.0 package: the new gradient and rotation modules and the Aurora lock-screen JPEG. These additions are version-gated to 9.6.0, JPEG content is signature-checked, and the bounded package limit now allows 84 files. Regression coverage confirms both installation of the 81-file AppDock 9.6.0 package and backward compatibility with earlier release tags.
