# Minecraft 3D 1.7.0

Die DApp erhält eine neue Touch-Steuerung. Unten links liegt ein virtueller Joystick: Ziehen oder Tippen in der oberen beziehungsweise unteren Hälfte bewegt den Spieler vorwärts oder rückwärts, links und rechts drehen die Kamera. Die bisherigen vier AppDock-Tasten und Hardware-Tasten bleiben als Fallback erhalten.

Eine eigene **Springen**-Taste startet eine kurze parabolische Kameraanimation. Zusätzlich können horizontale Wischgesten auf der Welt die Blickrichtung drehen; ein Wisch nach oben löst einen Sprung aus.

Alle Eingaben verwenden weiterhin die lokale Canvas und den bestehenden regionalen E-Ink-Refreshpfad. Die Steuerung benötigt keine externen Bibliotheken oder Hintergrunddienste.
