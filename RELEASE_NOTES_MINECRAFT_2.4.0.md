# Minecraft 3D 2.4.0

Für einen direkten Belastungstest wurde der logische Raycast auf **800×800** gesetzt. Es wurden keine weiteren Rendereränderungen vorgenommen. Diese Einstellung berechnet 640.000 Rays pro Frame und kann auf einem eInk-Gerät deutlich langsamer sein oder unvollständige Frames erzeugen; sie dient ausschließlich zum Testen der maximalen Auflösung.
