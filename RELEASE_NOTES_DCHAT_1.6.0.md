# DChat 1.6.0

- Die Empfängerliste dedupliziert weiterhin anhand der eindeutigen Geräte-ID und kann jetzt seitenweise durchblättert werden.
- In den Einstellungen kann das eigene DChat-Konto nach einer Bestätigung serverseitig gelöscht werden. Die Löschung wird auf dem öffentlichen und dem privaten DChat-Dienst versucht; fremde Konten können nicht gelöscht werden.
- Bereits veröffentlichte öffentliche Nachrichten bleiben nach der Kontolöschung bestehen.
