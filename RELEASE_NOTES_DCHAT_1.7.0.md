# DChat 1.7.0

DChat erhält eine WhatsApp-inspirierte Gesprächsansicht: private Nachrichten erscheinen jetzt als links- und rechtsbündige, unterschiedlich eingefärbte Chatblasen mit charakteristischem Eck-Tail. Eigene Nachrichten zeigen die kleinen Status-Häkchen am unteren Rand; ein blauer Doppelhaken steht für einen vorhandenen Lesezeitpunkt. Die Darstellung verwendet keine WhatsApp-Marken oder kopierten Assets.

Die Kontenverwaltung unterstützt jetzt bis zu zwölf lokale DChat-Profile auf demselben Reader. Jedes Profil behält seine eigene Geräte-ID, sein eigenes Geheimnis und seinen Anzeigenamen. Bestehende Einzelkonten werden beim ersten Start automatisch migriert. In den DChat-Einstellungen können Profile gewechselt, neue Konten hinzugefügt und das jeweils ausgewählte Konto einzeln vom öffentlichen und privaten Dienst gelöscht werden; andere Profile bleiben dabei erhalten.
