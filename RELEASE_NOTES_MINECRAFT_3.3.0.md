# Minecraft 3D 3.3.0

Die Hotbar sitzt jetzt dauerhaft am unteren Rand, zeigt Materialfarben und verfügbare Mengen und reagiert auf Slot-Tipps. Ein kurzer Tipp baut den sichtbaren angeklickten Block ab; längeres Halten platziert den ausgewählten Block an der getroffenen Blockfläche, wenn das angrenzende Feld frei ist. Inventarzähler und Voxel-Cache werden unmittelbar aktualisiert.
