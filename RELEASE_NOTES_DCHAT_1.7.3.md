# DChat 1.7.3 — DM recipient validation fix

Dieses Patchupdate behebt die irreführende Meldung `The request is invalid` beim Versand von Direktnachrichten.

- Das eigene Gerät wird nicht mehr als DM-Empfänger angeboten.
- Veraltete oder nicht mehr verfügbare Empfänger werden erkannt.
- Nach einem ungültigen Empfänger wird die Empfängerliste automatisch aktualisiert.
