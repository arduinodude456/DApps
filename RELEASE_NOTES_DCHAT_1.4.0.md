# DChat 1.4.0

Private Chats unterstützen jetzt kleine Bildanhänge. Über **Attach** kann eine PNG-, JPEG-, GIF- oder WEBP-Datei ausgewählt und zusammen mit optionalem Text an den Empfänger gesendet werden. Die Datei wird serverseitig gespeichert; die maximale Bildgröße beträgt 512 KB. Im Verlauf wird ein Bildanhang als `[image attachment]` markiert.

Zusätzlich zeigt DChat den Lesestatus direkt an: `✓` bedeutet serverseitig angenommen, `✓✓` bedeutet, dass der Empfänger die Konversation geöffnet und die Nachricht als gelesen markiert hat. In der Chatliste wird die Anzahl ungelesener Nachrichten am Empfänger angezeigt. Beim Öffnen einer Konversation werden eingegangene Nachrichten als gelesen markiert.
