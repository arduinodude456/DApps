# Minecraft 3D 1.9.0

## Höhere Renderauflösung

Das logische Raycasting-Raster wurde von maximal 120×90 auf maximal 180×120 erhöht. Die Ausgabe wird weiterhin per nearest-neighbour auf die Canvas skaliert und bleibt vollständig schwarzweiß mit Bayer-Dithering.

## Größere Sichtweite

Die maximale Raycast-Sichtweite wurde von 20 auf 28 Blöcke erhöht. Die prozedurale Welt ist von 32×32 auf 48×48 Blöcke gewachsen, damit der Spieler bei der langen Sichtweite nicht sofort die Weltkante sieht.
