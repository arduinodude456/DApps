# DChat 1.3.3

Behebt unsichtbare Emoji-Buttons. DChat prüft jetzt, ob das lokale PNG-Asset am tatsächlichen DApp-Pfad vorhanden ist. Wenn KOReader ein Paketbild nicht auflösen kann, zeigt der Button automatisch ein sichtbares Fallback-Symbol wie `:)`, `XD`, `<3`, `+1` oder `!!`.

Auf Geräten mit verfügbaren Assets werden weiterhin die lokalen Emoji-PNG-Bilder angezeigt.
