# DChat 1.2.8

Private Chats können jetzt über **Delete** gelöscht werden. Nach einer Bestätigung entfernt der Server die gesamte Konversation einschließlich der serverseitig gespeicherten Direktnachrichten für beide Teilnehmer.

Nur ein authentifizierter Teilnehmer kann die jeweilige Konversation löschen. Ein fremdes Gerät kann weder Nachrichten der Konversation löschen noch deren Inhalt sehen. Die Aktion ist nicht rückgängig machbar und wird im Client ausdrücklich bestätigt.
